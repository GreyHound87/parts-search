# parts-search

## Stack

React 19, Vite, JavaScript, Biome, Knip, Steiger, Bootstrap, CSS Modules.

## Commands

| Command               | What it does                          |
| --------------------- | ------------------------------------- |
| `npm run dev`         | Dev server                            |
| `npm run build`       | Prod                                  |
| `npm run preview`     | Local prod                            |
| `npm run biome:check` | Format & lint                         |
| `npm run biome:fix`   | Fixes & Format                        |
| `npm run knip`        | Unused files & exports & dependencies |
| `npm run knip:prod`   | Same, in prod                         |
| `npm run steiger`     | Check FSD                             |
| `npm run verify`      | All checks & build                    |
